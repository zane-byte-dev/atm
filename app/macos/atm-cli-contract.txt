# app/macos → atm CLI 契约清单
#
# 桌面 App 通过 fork/exec 调 atm，耦合方式是散在 Swift 里的 argv 数组。这份清单是那
# 份耦合的唯一显式声明，由 internal/cmd/app_contract_test.go 校验：
#
#   1. [commands] 每条路径必须能被 cobra 解析到，且该行列出的每个 flag 必须存在于
#      那条命令上（含继承来的全局 flag）。
#   2. 反向扫 Swift 源码：出现了这里没有的字面量 argv 数组，或者用了这里没记的
#      --flag，同样会红。
#   3. [config-keys] 每个键必须仍在 CLI 的可设置键表里。
#
# 所以删或改 CLI 时测试会红，而不是等运行时 App 静默失败。改了 Swift 的调用方式，
# 就要一起改这里。
#
# 动态拼装的调用扫不出来，靠这份清单显式记住；各 builder 里按条件追加的 flag
#（--desc、--image、--bin、--badge、--move-to 等）也在这里，不一定出现在同一个
# Swift 数组字面量里。
