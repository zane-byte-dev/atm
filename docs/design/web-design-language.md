# ATM Web 设计语言

Web 工作台以 Ant Design 6 作为交互组件基础，并由 ATM 自己的语义色板控制视觉。所有工作区共享同一侧栏、页面层级、控件尺寸和状态表达；任务创建与编辑使用同一套组合输入体验。

## 基础规则

| 用途 | 规则 |
| --- | --- |
| 页面 | 浅色画布、单一内容面板；侧栏负责全局导航，页面顶部只放当前工作区标题和主要操作。 |
| 字级 | 正文 14px、辅助文字 12–13px、页面标题 18px；标题字重约 620。 |
| 间距 | 以 4px 为基数，常用 8/12/16/24px；同级控件使用一致间隔。 |
| 圆角 | 控件 9px、面板 14px；弹窗和输入面板可用 18px。 |
| 颜色 | 使用 `themes.css` 中的 `--text`、`--muted`、`--surface`、`--canvas`、`--line`、`--accent` 及状态色；不在页面组件里硬编码主题色。 |
| 状态 | 错误、警告、成功分别使用语义色和对应浅色背景；禁用态仍需保留可读文字。 |

`DesignSystemProvider` 将当前主题的 CSS 变量映射到 Ant Design token，适配现有的 Minimal、Slate、Sage、Sand、Night 五套配色。共享外观规则放在 `design-system.css`；单个工作区的布局细节留在自己的样式文件。

## 组件约定

- 全局导航使用 Ant Design `Menu`，当前工作区只有一个选中项。
- 页面弹窗使用 Ant Design `Modal`，保留明确标题、关闭方式和主要操作；风险操作使用明确的确认文案。
- 常规操作使用 Ant Design `Button`；文本字段使用 `Input` / `Input.TextArea`，下拉使用 `Select`，可输入新项目的字段使用 `AutoComplete`。
- 共享 `components/select.tsx` 保留隐藏的原生 `select`，用于现有表单提交和校验；可见交互、搜索与键盘操作由 Ant Design 负责。文件选择、行选择等需要原生行为的控件按各工作区实际需求保留。
- 长内容先提供可阅读的正文，再显示辅助属性；空状态说明下一步可做什么。
- 小屏下保留图标导航的可访问名称；组合输入面板的属性行自动换行。

## 任务输入

创建与编辑共用一个多行输入区：首行是标题，后续行是说明。项目可选择已有项，也可直接输入新项目；优先级放在输入区下方。图片可通过按钮、粘贴或拖入添加。提交前仍沿用原有草稿保存、冲突合并和图片上传流程。

验证时检查工作板、收件箱、Agent、知识、统计、设置的页面层级，并覆盖创建/编辑任务、项目下拉、键盘提交和小屏布局。
