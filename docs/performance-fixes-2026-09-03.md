整合复核另修正了：归档和恢复跨独立请求的确认状态、不同刷新分支互相清除错误、同步后旧统计被标成新缓存，以及异步长文未完成时过早夹取阅读位置。

实机启动还发现独立归档请求先返回时会抢占默认选择。现分别记录首次 work / archive 读取完成状态，包含空结果与失败；默认选择优先等待工作数据，用户已有选择和未就绪的直接链接会保留。实际搜索另暴露了原有空记忆响应 `{"hits":null}` 被当成解码失败的问题：仅将显式 null 解释为空列表，缺键及错误格式仍报告异常。

使用同一台机器及现有 ATM 索引，不执行 sync。测量时其他应用仍运行，数据库内容可能随工作增长；这些数值是单次/重复请求结果，不是隔离基准或点击到首帧耗时。

| 修复后任务 + 今日摘要 | 0.1334 / 0.1317 s | 283,519 B |

日常任务刷新不再调用全量统计。全量接口仍保持原有范围和内容；加速来自减少当前页面不需要的查询及传输，不是让同一份完整统计从 9 秒降到 0.13 秒。单个范围的明细查询由 35 组降为 5 组，摘要只查询今日聚合。

独立临时数据库验证了 compact 与完整快照的所选范围数值相等，以及今日摘要不访问工具/技能明细表。请求字段为兼容性扩展，省略 `ranges` / `compact` 时保留旧响应。

## 回归与交付

最终实现通过 Go 全量测试、Go vet，以及配套新 CLI 的 Swift 全套 **606 项测试，0 失败**。Swift 最终测试和 Release 编译没有新增编译警告。

任务缓存测试使用 Debug 测试程序，最终一轮 2,000 条任务首次派生约 31.47 ms；随后 2,000 次选中查找合计 4.55 ms，分组构建次数保持为 1。该测试只测数据派生与查找，不包括 SwiftUI 布局、动画和屏幕显示。

已进行实机交互核验：今日 / 近 7 日范围切换，返回今日恢复对应数值与图表；知识工作区跨页返回仍保留所选文档；AI Day 返回保留历史页签。测试发现的启动顺序和空记忆兼容问题已补入回归。

验证日志：[Go 全量测试](/tmp/atm-perf-go-test.log)、[最终 dashboard / IPC 测试](/tmp/atm-perf-go-sections-test.log)、[Go vet](/tmp/atm-perf-go-vet.log)、[606 项 Swift 回归](/tmp/atm-perf-swift-test-final.log)、[Release 构建](/tmp/atm-perf-release-build.log)。

CLI 与 App 必须配套更新：旧 CLI 对新 `summary` section 及 `ranges` / `compact` 字段可能拒绝请求。本机 `/usr/local/bin/atm` 链接仓库 `bin/atm`，该二进制已重新构建，并用它执行 App 的真实 IPC 契约测试。

开发包脚本新增 `ATM_BUILD_CONFIGURATION=release` 和 `ATM_BUILD_ONLY=1`，默认仍为 Debug。Release 开发包沿用原 `ATM Dev.app` 标识，保留偏好；另生成常规签名包 `app/macos/dist/ATM.app`。可重复命令：

```sh
GOCACHE=/private/tmp/atm-go-cache make build
ATM_CONTRACT_EXECUTABLE=/Users/mj/mox/atm/bin/atm swift test --package-path app/macos
zsh app/macos/Scripts/build-app.sh
ATM_BUILD_CONFIGURATION=release ATM_BUILD_ONLY=1 zsh app/macos/Scripts/run-dev-app.sh
```

没有将后台 IPC 耗时等同于点击延迟。精确的点击到首帧 p50/p95，以及与具体 Web 实现的同机对照，仍需独立交互计时工具；本次不会把该预算写成已达标结论。
